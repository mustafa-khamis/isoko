Empty feature root cause:
The Admin Dashboard saves empty, "unconfigured", or deleted custom features inside the JSONB `features` column as placeholder characters such as `-`. The initial frontend implementation simply blindly iterated over `Object.values(plan.features)` and created a bullet point `<li>` for every single string it found, leading to bullets populated exclusively by hyphens.

Empty bullets remaining: No

Null/unlimited handling:
`max_active_listings` and `max_listings_per_period` explicitly check for `null` or `undefined` and output "Unlimited active listings" and "Unlimited listings" respectively.

Zero handling:
If `max_sponsored_ads_per_period` is strictly equal to `0`, the formatter returns "No sponsored ads included".

Singular/plural handling:
The formatter implements ternary checks on the numeric values (e.g., `value === 1 ? 'listing' : 'listings'`) before rendering them.

Listing quota wording:
Uses `max_listings_per_period` and dynamically appends `every {listing_period_days} days` only when the period exists.

Sponsored-ad wording:
Uses `max_sponsored_ads_per_period` and dynamically appends `every {sponsored_ads_period_days} days` only when the period exists.
